# jonmichaels/homebrew-tap

Homebrew formulae for my tools.

```console
$ brew install jonmichaels/tap/ctrl-kd
```

(or `brew tap jonmichaels/tap` once, then `brew install ctrl-kd`)

## Formulae

| Formula | What it is |
|---|---|
| **ctrl-kd** | Convert WordStar 4–7 documents and print-to-disk files to text, Markdown, HTML, RTF, or PDF (Python) — [source](https://github.com/jonmichaels/ctrl-kd) |
| **sr** | The Soft Return CLI — same conversions, native Swift, builds from source — [source](https://github.com/jonmichaels/soft-return) |
